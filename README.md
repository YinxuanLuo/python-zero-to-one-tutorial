## 三、怎么用这份教程（重要，别跳过）

### 每个知识点的学习循环

```
读讲解  →  敲代码  →  故意改错看报错  →  说出"一句话记住它"
 5 min     5 min        3 min                1 min
```

**"故意改错看报错"是整份教程里最值钱的动作。**
大多数人对 Python 的恐惧来自"报错了一脸懵"。
你把错误故意制造出来 20 次之后，报错就变成了朋友——它是在你上线之前替你挨骂。

教程里每一处报错都是**从真实运行环境上抄下来的**，不是编的。
所以你也可以自己复现：把代码改坏，看看是不是同一句报错。

### 三条铁律

1. **不要背 API。** Python 的核心只有十来个概念（对象模型、作用域、异常、迭代器、GIL），其余全是组合出来的。
2. **不要一开始就上框架。** 先用标准库 + `http.server` 把请求响应摸明白，再上 Flask/FastAPI（第 09 章带你走一遍）。
3. **看不懂的代码，先 `print` 出来。** Python 的 REPL（交互式解释器）是你最好的调试器，比盯着代码看快十倍。

## 四、把环境跑起来

你只需要 **Python**（建议 **3.12 或 3.13**，本教程基于 3.13 实测）。

```bash
python --version   # 应该输出 Python 3.12.x 或 3.13.x
```

**核心章节几乎零依赖**——大多数示例只用标准库。只有少数章节（爬虫用 `requests`、测试用 `pytest`、
实战用 `flask`）需要装第三方库，这些都在对应章节里明确写了 `pip install` 命令。

随便挑一个示例验证：

```bash
python examples/00-设计哲学.py
```

能看到输出，就说明环境没问题。再试一个更能说明问题的：

```bash
python examples/03-函数.py          # 闭包、装饰器
python examples/06-并发.py          # 线程 vs 进程 vs asyncio
python examples/project/smoke-test.py   # 分层 API 服务端到端自测
```

### 一个真实的坑（值得提前知道）

如果你把示例文件存成 `.txt` 或者用记事本保存，很可能带上 **BOM** 或**错误的编码**，
Python 3 的源码默认是 UTF-8，但 Windows 控制台默认是 GBK，于是中文输出会乱码甚至报错：

```text
UnicodeDecodeError: 'gbk' codec can't decode byte 0x80 in position 0: illegal multibyte sequence
```

**本仓库的做法**：示例统一用 `.py` + UTF-8 编码，需要输出中文时用标准库的 `sys.stdout` 或直接
在文件头标注编码。这也是第 01 章要专门讲清的第一件事。

> 补充三点：
> - Python 3 源码默认 UTF-8，但**控制台编码**是另一回事，Windows 下最容易踩——第 01 章。
> - `python` 和 `py`（Windows 的 Python launcher）是两个东西，多个版本共存时 `py` 更好用——第 01 章。
> - 缩进是语法，混用 Tab 和空格会报 `IndentationError`——第 02 章。

## 六、先看三段代码，找找感觉

别怕看不懂，先感受一下 Python 和"浏览器 JS"的差别。

**第一段：可读性——缩进就是语法**

```python
def greet(name):
    if name:                    # 缩进表达层次，不是 {} 也不是 ;
        print(f"hello, {name}")
    else:
        print("hello, stranger")

greet("world")   # hello, world
```

**第二段：数据结构——推导式一行顶 JS 三行**

```python
nums = [1, 2, 3, 4, 5]

# 一行：把偶数翻倍
doubled = [n * 2 for n in nums if n % 2 == 0]
print(doubled)   # [4, 8]
```

**第三段：上下文管理器——`with` 自动关闭资源**

```python
# with 块结束时，文件自动关闭，不用手写 finally
with open("data.txt", "r", encoding="utf-8") as f:
    content = f.read()
print(len(content))
```

看出来了吗？

**Python 不是"语法更短的 JS"，它是"用可读性和生态，换取开发者时间"的语言。**
理解了这一点，缩进、鸭子类型、GIL、`venv` 全都是它的推论。

剩下的都是细节。

## 七、承诺与免责

**这份教程保证：**

- 每个知识点都有可运行的代码，**全部在 Python 3.13 上实测跑通**。
- 每处报错信息都是从真实运行环境上抄下来的，包含异常类型，你可以自己复现。
- 讲"为什么这么设计"，不只是"怎么写"。第 00 章引用了 Zen of Python 原文。
- **核心章节零第三方依赖**——只用标准库，不会因为某个包升级而失效。

**这份教程不保证：**

- 让你成为性能调优专家（那需要在真实线上环境里练）。
- 覆盖所有边角 API（那需要查手册，而查手册是正常的工作方式）。
- 教你具体某个框架（Django/FastAPI 等）。**本教程刻意只用一个轻量 Flask**，
  因为框架会过期，而 Python 的对象模型和并发模型不会。
