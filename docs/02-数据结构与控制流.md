## 2.1 四个容器：一张表先记住

先给结论，一张表把 Python 的四个核心容器讲完：

| 类型 | 写法 | 可变 | 有序 | 元素能否重复 | 可哈希（能作 dict 的键） | 典型用途 |
|---|---|---|---|---|---|---|
| `list` | `[1, 2, 3]` | ✅ 可变 | ✅ 有序 | ✅ 可重复 | ❌ | 顺序集合，最常用 |
| `tuple` | `(1, 2, 3)` | ❌ 不可变 | ✅ 有序 | ✅ 可重复 | ✅ | 固定记录、作字典键 |
| `dict` | `{"a": 1}` | ✅ 可变 | ✅ 有序(3.7+) | 键不可重复 | 键必须可哈希 | 键值映射 |
| `set` | `{1, 2, 3}` | ✅ 可变 | ❌ 无序 | ❌ 自动去重 | ❌ | 去重、集合运算 |

这张表里有三个词，你现在可能半懂不懂，但它们是理解 Python 的关键，先记个印象，本章后面逐个展开：

- **可变（mutable）**：创建之后，内容能不能改。能改的是 `list`/`dict`/`set`，不能改的是 `tuple`（以及 `int`/`str`）。
- **有序（ordered）**：元素的排列顺序是不是固定的、可预期的。`list`/`tuple` 有序；`set` 无序（你看到的打印顺序是"碰巧"的）。
- **可哈希（hashable）**：能不能作为 `dict` 的键。只有**不可变**对象才能哈希，所以 `tuple` 能作键，`list` 不能。

先直观感受一下四个容器长什么样、怎么创建：

```python
names = ["alice", "bob", "carol"]        # list：方括号，可变、有序
point = (3, 4)                            # tuple：圆括号，不可变、有序
user = {"name": "alice", "age": 30}       # dict：花括号 + 冒号，键值对
tags = {"python", "js", "python"}         # set：花括号，自动去重

print(names)   # ['alice', 'bob', 'carol']
print(point)   # (3, 4)
print(user)    # {'name': 'alice', 'age': 30}
print(tags)    # {'python', 'js'}   ← 注意 "python" 只出现了一次，自动去重
```

运行结果：

```text
['alice', 'bob', 'carol']
(3, 4)
{'name': 'alice', 'age': 30}
{'python', 'js'}
```

### 一个容易混的点：`set` 和 `dict` 都长在花括号里

`{"a", "b"}` 是 set，`{"a": 1}` 是 dict。区别在哪？**看有没有冒号。**

- `{1, 2, 3}` → set（只有元素，没有冒号）
- `{"a": 1}` → dict（有冒号，键值对）

但有个坑：**空的花括号 `{}` 是空 dict，不是空 set！** 空 set 要用 `set()`：

```python
d = {}        # 这是空 dict
s = set()     # 这才是空 set

print(type(d))   # <class 'dict'>
print(type(s))   # <class 'set'>
```

为什么这么设计？因为 `dict` 出现得比 `set` 早，`{}` 这个写法早就被 dict 占用了，set 只能委屈用 `set()`。
这是历史遗留，记住"空 set 用 `set()`"就行。

### 什么时候用哪个

| 你的需求 | 用哪个 | 原因 |
|---|---|---|
| 装一组东西，顺序有意义，还要增删改 | `list` | 可变、有序，方法最全 |
| 装一组固定的东西（比如坐标、配置项），永不变 | `tuple` | 不可变，省内存，能作键 |
| 通过"名字/键"查"值"（查配置、查缓存） | `dict` | O(1) 查找，最快 |
| 只要"有没有出现过"，不关心顺序（去重、判存在） | `set` | 自动去重，O(1) 判存在 |

> 一句话记住它：**`list` 装可变的顺序集合，`tuple` 装不变的固定记录，`dict` 用键查值，`set` 去重判存在——而"可变/不可变"是它们最本质的分界线。**

## 2.2 list：最常用的可变序列

**list 是 Python 的 `Array`**，但比 JS 的数组强大得多。它是你写 Python 时出场率最高的容器。

### 创建和索引

```python
nums = [10, 20, 30, 40]
mixed = [1, "two", 3.0, [4, 5]]   # 列表可以装任意类型的混合元素

print(nums[0])      # 10，正索引从 0 开始
print(nums[-1])     # 40，负索引从右边数，-1 是最后一个
print(nums[-2])     # 30

print(len(nums))    # 4，长度用 len() 函数，不是 .length 属性
```

运行结果：

```text
10
40
30
4
```

注意一个和 JS 的差异：**JS 用 `arr.length`（属性），Python 用 `len(arr)`（函数）**。
`len()` 是内置函数，不是方法。这是 Python 一贯的风格——"获取长度"这种通用操作，用统一的 `len()` 函数。

### 越界访问会报什么

```python
nums = [1, 2, 3]
print(nums[10])
```

真实报错：

```text
IndexError: list index out of range
```

### 常用方法：增删改查

```python
nums = [3, 1, 2]

nums.append(4)        # 尾部追加一个元素
print(nums)           # [3, 1, 2, 4]

nums.sort()           # 原地排序（默认升序）
print(nums)           # [1, 2, 3, 4]

nums.insert(0, 99)    # 在索引 0 的位置插入 99，其余后移
print(nums)           # [99, 1, 2, 3, 4]

last = nums.pop()     # 弹出并返回最后一个元素（默认 -1）
print(last, nums)     # 4 [99, 1, 2, 3]

nums.remove(99)       # 按"值"删除第一个匹配的元素
print(nums)           # [1, 2, 3]

print(nums.index(3))  # 2，返回值的索引
print(nums.count(2))  # 1，返回某个值出现的次数

nums.reverse()        # 原地反转
print(nums)           # [3, 2, 1]
```

运行结果：

```text
[3, 1, 2, 4]
[1, 2, 3, 4]
[99, 1, 2, 3, 4]
4 [99, 1, 2, 3]
[1, 2, 3]
2
1
[3, 2, 1]
```

几个要点：

- **`sort()` 和 `reverse()` 是"原地修改"**，不返回新列表，直接改原来的列表，返回 `None`。新手常踩的坑是写 `nums = nums.sort()`，结果 `nums` 变成 `None`。
- **`pop()` 返回被删掉的元素**，`remove()` 返回 `None`。
- `remove(x)` 删除**第一个**等于 `x` 的元素；如果列表里没有 `x`，会报 `ValueError`。

### `append` 和 `extend` 的区别（高频考点）

```python
a = [1, 2]
a.append([3, 4])      # append 把整个 [3,4] 当成"一个元素"塞进去
print(a)              # [1, 2, [3, 4]]

b = [1, 2]
b.extend([3, 4])      # extend 把 [3,4] 的每个元素"逐个"塞进去
print(b)              # [1, 2, 3, 4]
```

`append` 是"加一个元素"，`extend` 是"合并另一个序列"。面试常考，务必分清。

> 一句话记住它：**list 是可变、有序的序列，`append` 加一个元素、`extend` 合并序列、`sort`/`reverse` 是原地修改返回 `None`，长度用 `len()` 函数。**

## 2.3 tuple：不可变的 list 兄弟

**tuple 和 list 长得几乎一样，唯一（也是最关键）的区别是：tuple 一旦创建，内容就不能改。**

```python
point = (3, 4)
user = ("alice", 30)

print(point[0])       # 3，索引和 list 一样
print(len(point))     # 2
print(user)           # ('alice', 30)
```

### 试着改它，会看到真实报错

```python
point = (3, 4)
point[0] = 99
```

```text
TypeError: 'tuple' object does not support item assignment
```

这句报错字面意思就是："`tuple` 对象不支持元素赋值"。它没有 `append`、没有 `remove`、没有 `sort`，
所有"改"的方法都没有。

### 那 tuple 到底有什么用？

你可能会想："不能改的东西，我要它干嘛？" tuple 有三个 list 替代不了的用处：

**用处一：保护数据不被意外修改。** 有些数据天生就不该变——坐标、颜色 RGB、配置项。用 tuple 表示，
等于告诉读代码的人（包括未来的你）："这个东西是常量，别动它。"

**用处二：可以作 `dict` 的键、可以进 `set`。** 因为不可变才能哈希（2.6 节细讲），而 `list` 不行：

```python
locations = {
    (39.9, 116.4): "北京",     # ✅ tuple 能作键
    (31.2, 121.5): "上海",
}
print(locations[(39.9, 116.4)])   # 北京

# 如果用 list 作键，会报错：
d = {}
d[[1, 2]] = "x"                  # ❌
```

真实报错：

```text
TypeError: unhashable type: 'list'
```

**用处三：`tuple` 更省内存、更安全。** 因为它不可变，解释器能做一些优化，创建开销也比 list 小。
在一些"只读不写"的场景，用 tuple 是更优选择。

### 单元素 tuple 的坑

写一个"只有一个元素的 tuple"，新手几乎必错：

```python
t = (1)          # ❌ 这不是 tuple！这是整数 1，括号只是"运算优先级"
print(type(t))   # <class 'int'>

t = (1,)         # ✅ 这才是单元素 tuple，靠的是那个逗号
print(type(t))   # <class 'tuple'>
```

**记住：tuple 的识别标志是逗号，不是括号。** `(1)` 是整数，`(1,)` 才是单元素 tuple。
同样，`1, 2, 3` 不加括号也是一个 tuple（这叫"元组打包"，2.9 节会用到）。

> 一句话记住它：**tuple 是不可变的 list，能作字典键、能保护数据不被改；它的识别标志是逗号不是括号，单元素 tuple 要写成 `(1,)`。**

## 2.4 dict：键值映射

**dict 对应 JS 的对象（Object）/ Map**，是"键 → 值"的映射。但 Python 的 dict 比 JS 的普通对象严谨得多：
键几乎可以是任意不可变类型（不只是字符串）。

### 创建、取值、增删改

```python
user = {"name": "alice", "age": 30}

print(user["name"])       # alice，用方括号取值

user["city"] = "北京"     # 新增一个键值对（直接赋值即可）
print(user)               # {'name': 'alice', 'age': 30, 'city': '北京'}

user["age"] = 31          # 修改已有键的值
print(user["age"])        # 31

del user["city"]          # 删除一个键
print(user)               # {'name': 'alice', 'age': 31}
```

### 取一个不存在的键，会报错

```python
user = {"name": "alice"}
print(user["age"])
```

真实报错：

```text
KeyError: 'age'
```

**`KeyError` 是 Python 里最高频的报错之一**。它翻译过来就是："你要的键不存在。"

### 三种安全的取值方式

既然直接 `d[key]` 会报错，那怎么"安全地"取值？

**方式一：`get()`——取不到就给默认值，不报错**

```python
user = {"name": "alice"}

print(user.get("age"))        # None，键不存在返回 None（不报错）
print(user.get("age", 0))     # 0，可以自定义默认值
```

`get(key, default)` 是查 dict 最常用的方法，**永远优先用它，而不是 `d[key]`**，
除非你确定键一定存在、或者你希望键不存在时直接报错。

**方式二：`in` 判断键是否存在**

```python
if "age" in user:
    print(user["age"])
else:
    print("没有 age 这个键")
```

**方式三：`setdefault()`——有就取，没有就设置并返回**

```python
counts = {}
counts.setdefault("apple", 0)   # 键不存在，设置成 0 并返回 0
counts["apple"] += 1            # 现在可以安全地 +1
print(counts)                   # {'apple': 1}
```

`setdefault` 是"计数场景"的神器，第 06 章做统计时你会天天用。

### 遍历 dict

```python
user = {"name": "alice", "age": 30}

for key in user:                     # 直接遍历，拿到的是键
    print(key, user[key])

for key, value in user.items():      # items() 拿到 (键, 值) 对，配合解包
    print(key, value)

print(list(user.keys()))             # ['name', 'age']
print(list(user.values()))           # ['alice', 30]
print(list(user.items()))            # [('name', 'alice'), ('age', 30)]
```

**`items()` 是最常用的遍历方式**，配合 2.9 节的解包，`for k, v in d.items()` 一行就能同时拿到键和值。

> 一句话记住它：**dict 是键值映射，直接 `d[key]` 取不存在的键会报 `KeyError`；安全取值用 `d.get(key, 默认值)`，遍历用 `for k, v in d.items()`。**

## 2.5 set：去重和集合运算

**set 对应数学里的"集合"**，两个核心特点：**元素不重复、元素无序**。

### 自动去重

```python
nums = [1, 2, 2, 3, 3, 3]
unique = set(nums)          # 列表转集合，自动去重
print(unique)               # {1, 2, 3}
```

"列表去重"是 set 最经典的用途，一行搞定：

```python
nums = [1, 2, 2, 3, 3, 3]
print(list(set(nums)))      # [1, 2, 3]，去重后再转回列表
```

### 集合运算：并集、交集、差集

这是 set 真正值钱的地方，比手写循环优雅得多：

```python
a = {1, 2, 3}
b = {2, 3, 4}

print(a | b)    # {1, 2, 3, 4}   并集：两个集合合起来
print(a & b)    # {2, 3}         交集：共有的
print(a - b)    # {1}            差集：a 有而 b 没有的
print(a ^ b)    # {1, 4}         对称差：只在一个集合里的
```

运行结果：

```text
{1, 2, 3, 4}
{2, 3}
{1}
{1, 4}
```

### 判存在：O(1)

```python
if "python" in {"python", "js", "go"}:
    print("在集合里")
```

`in` 判断元素在不在集合里，是 **O(1)** 常数时间（因为 set 底层是哈希表），
而判断"在不在 list 里"是 **O(n)** 线性时间。**集合很大时，set 的 `in` 比 list 的 `in` 快几个数量级**——这是 2.1 那张表说 set "O(1) 判存在"的原因。

### 无序带来的注意点

set 是无序的，所以**不能索引**：

```python
s = {1, 2, 3}
print(s[0])
```

真实报错：

```text
TypeError: 'set' object is not subscriptable
```

（"not subscriptable" = "不能用下标访问"。同理，`dict` 也不能用下标 `d[0]` 访问，只能用键。）

> 一句话记住它：**set 是"去重 + 集合运算 + O(1) 判存在"的利器，但元素无序、不能索引；判存在用 `x in s`，去重用 `list(set(xs))`。**

## 2.6 可变 vs 不可变：Python 最核心的概念

这一节是全章（甚至全书）最重要的概念。**搞懂它，后面函数传参、默认参数、深浅拷贝、并发安全，全是它的推论。**

### 先记住两组名单

**不可变（immutable）**：`int`、`float`、`bool`、`str`、`tuple`、`frozenset`、`None`。
**可变（mutable）**：`list`、`dict`、`set`。

**不可变 = 创建之后，内容永远不能改。** "改"一个不可变对象，实际是**创建了一个新对象**，旧的还在原地没动。

### 用一个 `id()` 实验看穿本质

`id(obj)` 能返回一个对象的"内存地址"（身份的标识）。两个对象如果 `id` 相同，就是同一个对象。

先看**可变对象（list）**：

```python
a = [1, 2, 3]
print(id(a))          # 比如 140234567890

a.append(4)           # 原地修改
print(id(a))          # 140234567890，id 没变！还是原来那个对象
print(a)              # [1, 2, 3, 4]
```

`a.append(4)` 之后，`a` 的 `id` 没变——**说明是"同一个对象原地被改了"**。

再看**不可变对象（str）**：

```python
s = "hello"
print(id(s))          # 比如 140234500000

s = s + " world"      # 看似"修改"，其实是创建了新字符串
print(id(s))          # 140234600000，id 变了！是另一个新对象
print(s)              # 'hello world'
```

`s = s + " world"` 之后，`s` 的 `id` 变了——**说明旧的 `"hello"` 没被动，而是新建了一个 `"hello world"`**。

这就是"可变 vs 不可变"的本质：

- **可变对象**：改 = 原地改，所有指向它的变量都看到变化。
- **不可变对象**：改 = 造一个新的，原来的不受影响。

### 为什么"赋值"在两种对象上行为完全不同

这是新手最容易栽的地方。看这段代码：

```python
# 可变对象：b = a 是"同一个对象"的引用
a = [1, 2, 3]
b = a                # b 和 a 指向同一个列表
b.append(4)
print(a)             # [1, 2, 3, 4]  ← a 也变了！因为 a 和 b 是同一个对象
```

```python
# 不可变对象：b = a 是"值"的复制（其实是新绑定）
a = 10
b = a                # b 和 a 都是 10
b = b + 1            # b 变成 11（新对象）
print(a)             # 10  ← a 没变
```

**同样是 `b = a`，为什么结果不同？**

因为 Python 的变量名只是"指向对象的标签"。`b = a` 这个动作，含义是"让 `b` 这个标签也指向 `a` 指向的那个对象"。

- 如果指向的是**可变对象**（list），那么 `b` 和 `a` 是**同一个对象**，通过 `b` 改它，`a` 当然也看到变化。
- 如果指向的是**不可变对象**（int），那么"改 `b`"这个动作（`b = b + 1`）**不是原地改那个 10**，
  而是让 `b` 指向一个新的 11。原来的 10 还在，`a` 还指向它，所以 `a` 没变。

**关键结论：Python 的赋值永远是"绑定标签"，不是"复制值"。** 可变对象共享同一个"身体"，不可变对象改的时候换"身体"。

### 一个最经典的坑：可变对象作默认参数

这个坑在 00 章预告过，这里正式讲（因为它就是"可变 vs 不可变"的直接后果）：

```python
def add_item(item, cart=[]):      # ❌ 默认参数是可变对象 []
    cart.append(item)
    return cart

print(add_item("apple"))          # ['apple']
print(add_item("banana"))         # ['apple', 'banana']  ← 你以为是 ['banana']！
```

**为什么第二次调用会带着第一次的 "apple"？**

因为 `cart=[]` 里的这个 `[]` 只在**函数定义时创建一次**。之后每次调用，用的都是**同一个**列表对象。
第一次 `append("apple")` 改了这个列表，第二次调用时它已经装了 "apple"。

**正确做法：默认参数用不可变的 `None`，在函数内部再判断：**

```python
def add_item(item, cart=None):    # ✅ 默认参数用 None
    if cart is None:
        cart = []                 # 每次调用都新建一个列表
    cart.append(item)
    return cart

print(add_item("apple"))          # ['apple']
print(add_item("banana"))         # ['banana']  ← 正确了
```

### `is` vs `==`：不可变对象带来的另一个坑

`==` 比较**值**，`is` 比较**身份**（是不是同一个对象）。对不可变对象，CPython 会做一些"缓存"优化，导致 `is` 的结果不可预测：

```python
print(1 == 1)          # True，值相等
print(1 is 1)          # True，小整数被缓存

a = 256
b = 256
print(a is b)          # True，[-5, 256] 的小整数被 CPython 缓存，都是同一个对象

a = 257
b = 257
print(a is b)          # 结果不确定！我在 REPL 里逐行输入得到 False，同一行写则得到 True
```

最后那个 `257 is 257` 的结果，取决于 CPython 的实现细节（小整数缓存、常量折叠、字符串驻留），**不是一个你可以依赖的行为**。

**所以 Python 社区的铁律是：**

- **比较值，用 `==`。**
- **比较身份，只有一种情况用 `is`——判断是不是 `None`：`if x is None:`**

其他地方（包括比较 `True`/`False`、比较整数、比较字符串），一律用 `==`。把 `is` 当 `==` 用，是新手到中级的必经一坑。

> 一句话记住它：**可变对象（list/dict/set）赋值是"共享同一个身体"，改一个所有引用都变；不可变对象（int/str/tuple）"改"是"换新身体"；所以可变对象不能作默认参数，比较值用 `==`，只有判 `None` 用 `is`。**

## 2.7 切片：Python 最优雅的特性之一

**切片（slicing）是"从一个序列里取一段"的语法**，格式是 `[start:stop:step]`。它作用于所有序列——`list`、`tuple`、`str`。

### 规则：左闭右开

```python
s = "hello world"

print(s[0:5])    # 'hello'   从索引 0 到 5（不含 5）
print(s[6:11])   # 'world'   从 6 到 11（不含 11）
```

**`[start:stop]` 是"左闭右开"区间**：包含 `start`，不包含 `stop`。这和 `range()` 的规则一致，是 Python 一个贯穿始终的设计。

你可能要问：为什么要"右开"？因为这样有个优雅的性质——**`s[0:n]` 正好取 n 个元素**，`s[a:b]` 的长度正好是 `b - a`。
而且 `s[:i] + s[i:] == s` 这种"切两半再拼回来"的操作不用做任何 `+1/-1` 调整。

### 省略边界

```python
s = "hello world"

print(s[:5])     # 'hello'   省略 start，默认从 0 开始
print(s[6:])     # 'world'   省略 stop，默认到末尾
print(s[:])      # 'hello world'  都省略，就是整个序列的拷贝
```

### 负索引：从右边数

```python
s = "hello world"

print(s[-1])     # 'd'       最后一个
print(s[-5:])    # 'world'   从倒数第 5 个到末尾
print(s[:-6])    # 'hello'   到倒数第 6 个（不含）
```

### 步长 `step`：隔几个取一个

```python
nums = [0, 1, 2, 3, 4, 5]

print(nums[::2])    # [0, 2, 4]   从头到尾，步长 2（隔一个取一个）
print(nums[1::2])   # [1, 3, 5]   从索引 1 开始，步长 2
print(nums[::3])    # [0, 3]      步长 3
```

### 反向步长：`[::-1]` 反转（面试必考）

```python
nums = [0, 1, 2, 3, 4, 5]

print(nums[::-1])    # [5, 4, 3, 2, 1, 0]   整个序列反转
```

`[::-1]` 是最优雅的反转写法——比 JS 的 `arr.reverse()` 更简洁（而且它不修改原列表，返回新列表）。
`str` 也能反转：

```python
print("hello"[::-1])   # 'olleh'
```

### 切片也能用在赋值上（可变序列）

```python
nums = [0, 1, 2, 3, 4, 5]
nums[1:3] = [99, 98, 97]    # 把索引 1~2 替换成 [99, 98, 97]
print(nums)                 # [0, 99, 98, 97, 3, 4, 5]

nums[1:1] = [100]           # 在索引 1 处插入（空切片赋值 = 插入）
print(nums)                 # [0, 100, 99, 98, 97, 3, 4, 5]

del nums[1:3]               # 删除切片
print(nums)                 # [0, 98, 97, 3, 4, 5]
```

这是 list 特有的能力（tuple 和 str 不可变，不能这样赋值）。

> 一句话记住它：**切片 `[start:stop:step]` 左闭右开，负索引从右边数，`[::-1]` 反转、`[::2]` 隔一取一——它优雅就优雅在"取一段"和"数学区间"直觉完全一致。**

## 2.8 推导式：一行顶 JS 三行

**推导式（comprehension）是"用一行代码，从已有的序列生成新的序列"的语法**。它对应 JS 里的 `map` + `filter` 的组合，但更短、更可读。

### 列表推导式

```python
nums = [1, 2, 3, 4, 5]

squares = [n * n for n in nums]            # map：每个元素平方
print(squares)                             # [1, 4, 9, 16, 25]

evens = [n for n in nums if n % 2 == 0]    # filter：只保留偶数
print(evens)                               # [2, 4]

doubled_evens = [n * 2 for n in nums if n % 2 == 0]   # map + filter 一起
print(doubled_evens)                       # [4, 8]
```

对比一下 JS 的写法，体会什么叫"一行顶三行"：

```js
// JavaScript
const doubledEvens = nums.filter(n => n % 2 === 0).map(n => n * 2);
```

```python
# Python
doubled_evens = [n * 2 for n in nums if n % 2 == 0]
```

语法结构拆开看：

```text
[ 表达式  for  变量  in  序列  if  条件 ]
   ↑       ↑        ↑      ↑       ↑
 每个元素  取个名字   遍历   可选    可选
 算什么    给它      哪里   过滤    过滤
```

### 字典推导式

```python
squares = {n: n * n for n in range(5)}
print(squares)    # {0: 0, 1: 1, 2: 4, 3: 9, 4: 16}

# 翻转键值
d = {"a": 1, "b": 2}
flipped = {v: k for k, v in d.items()}
print(flipped)    # {1: 'a', 2: 'b'}
```

### 集合推导式

```python
tags = ["python", "js", "python", "go"]
unique = {t for t in tags}
print(unique)    # {'python', 'js', 'go'}  自动去重
```

### 生成器表达式：省内存的"懒"推导式

把推导式的方括号换成圆括号，就得到一个**生成器表达式（generator expression）**：

```python
gen = (n * n for n in range(3))
print(gen)            # <generator object <genexpr> at 0x...>
print(list(gen))      # [0, 1, 4]，转成 list 才能看到内容
```

**它和列表推导式的区别是"惰性"**：列表推导式会立刻把所有结果算出来、放进内存；
生成器表达式**不立刻计算**，而是"你取一个，我算一个"。

这对"数据量巨大"的场景是救命稻草——比如你要处理 1 亿个数字的平方，列表推导式会瞬间吃满内存，
生成器表达式则几乎不占内存。生成器是第 03 章的大主题，这里先记住"圆括号 = 惰性"这个印象。

### 什么时候别用推导式

推导式虽好，但**别为了炫技硬套**。一个判断标准：**如果推导式超过一行，或者嵌套了两层，就拆成普通循环**。
可读性永远是第一位的（第 00 章的总纲）：

```python
# ❌ 过度嵌套，读起来要命
result = [y for x in matrix for y in x if y > 0]

# ✅ 拆开，清楚多了
result = []
for row in matrix:
    for y in row:
        if y > 0:
            result.append(y)
```

> 一句话记住它：**推导式是"从序列生成序列"的一行写法，方括号=列表、花括号带冒号=字典、花括号=集合、圆括号=惰性生成器；超过一行就拆成普通循环，别炫技。**

## 2.9 解包：多值赋值一行搞定

**解包（unpacking）是"把一个序列里的元素，一次性拆开赋给多个变量"的语法。** 它让 Python 的赋值语句优雅得离谱。

### 基本解包

```python
a, b = 1, 2            # 右边打包，左边解包
print(a, b)            # 1 2

x, y = (3, 4)          # 解包 tuple
print(x, y)            # 3 4

name, age = ["alice", 30]   # 解包 list
print(name, age)       # alice 30
```

**左边变量个数必须和右边元素个数一致**，否则报错：

```python
a, b = [1, 2, 3]
```

真实报错：

```text
ValueError: too many values to unpack (expected 2)
```

### 用解包交换两个变量（无需临时变量）

```python
a = 1
b = 2
a, b = b, a           # 一行交换！
print(a, b)           # 2 1
```

对比 JS，你需要一个临时变量 `let tmp = a; a = b; b = tmp;`。Python 一行搞定。这是面试最爱考的小知识点。

### 星号解包：`*` 收集多余的元素

```python
first, *rest = [1, 2, 3, 4]
print(first)          # 1
print(rest)           # [2, 3, 4]  星号变量收集"剩下的"，是个 list

first, *middle, last = [1, 2, 3, 4, 5]
print(first, middle, last)    # 1 [2, 3, 4] 5
```

`*rest` 的意思是"把剩下的元素都装进 `rest`"。这对应 JS 里的**剩余参数**（rest parameters）`...rest`。

### 遍历时的解包：`enumerate` 和 `zip`

这是解包最实用的场景，配合 `for` 循环。

**`enumerate`：同时拿到下标和元素。**

```python
names = ["alice", "bob", "carol"]

for i, name in enumerate(names):
    print(i, name)
```

```text
0 alice
1 bob
2 carol
```

`enumerate(xs)` 会产出 `(下标, 元素)` 这样的 tuple，再用 `i, name` 解包。它对应 JS 里
`arr.forEach((name, i) => ...)` 或 `for (let i = 0; i < arr.length; i++)` 的下标需求。

**`zip`：把多个序列"拉链"在一起。**

```python
names = ["alice", "bob", "carol"]
scores = [90, 85, 95]

for name, score in zip(names, scores):
    print(name, score)
```

```text
alice 90
bob 85
carol 95
```

`zip(a, b)` 会把两个序列"配对"成 `(a[0], b[0])`、`(a[1], b[1])`…… 再解包。

一个注意点：**`zip` 默认按最短的序列截断**：

```python
print(list(zip([1, 2], ["a", "b", "c"])))   # [(1, 'a'), (2, 'b')]  ← "c" 被丢掉了
```

如果两个序列长度不一致，`zip` 只会配到最短那个为止，多余的直接忽略。

> 一句话记住它：**解包是把序列拆开赋给多个变量，`a, b = b, a` 一行交换，`*rest` 收集剩余，`enumerate` 拿下标、`zip` 配对多个序列——这三个组合是 Python 循环的"标准姿势"。**

## 2.10 控制流

控制流是 Python 和 JS 差异最大、也最需要重新适应的地方。核心变化：**用缩进代替 `{}`，用 `and/or/not` 代替 `&&/||/!`。**

### `if / elif / else`

```python
score = 85

if score >= 90:
    grade = "A"
elif score >= 80:          # 注意：是 elif，不是 else if！
    grade = "B"
elif score >= 60:
    grade = "C"
else:
    grade = "D"

print(grade)               # B
```

三个关键点：

1. **`elif` 不是 `else if`**，这是 JS 程序员最容易写错的地方——Python 把它缩成了一个词。
2. **条件不用加括号**：`if score >= 90:` 而不是 `if (score >= 90) {`。
3. **冒号 `:` 结尾**：每个 `if`/`elif`/`else`/`for`/`while`/`def` 后面都有冒号，它标记"代码块开始"。

### 三目运算符：`a if cond else b`

JS 里你写 `cond ? a : b`，Python 的写法是：

```python
age = 20
status = "成年" if age >= 18 else "未成年"
print(status)      # 成年
```

注意顺序是 `真值 if 条件 else 假值`，和 JS 的 `条件 ? 真值 : 假值` 顺序不同，别写反。

### `for` 循环：直接遍历，不需要 `i++`

这是 Python 循环和 JS 最大的观念差异。**Python 的 `for` 直接遍历元素本身，而不是下标：**

```python
names = ["alice", "bob", "carol"]

for name in names:        # 直接拿到元素
    print(name)
```

```text
alice
bob
carol
```

对比 JS 的老式写法 `for (let i = 0; i < names.length; i++) { names[i] }`，Python 直接给你元素，
因为你 99% 的时候要的就是元素本身，不是下标（00 章 0.9 讲过）。

**遍历字符串：**

```python
for ch in "abc":
    print(ch)
# a / b / c
```

**遍历 dict（默认拿到键）：**

```python
d = {"a": 1, "b": 2}
for k in d:
    print(k)          # a / b（拿到的是键）
```

### `range`：需要"数字序列"时用它

当你确实需要"循环 N 次"或"遍历一串数字"时，用 `range()`：

```python
for i in range(5):        # 0, 1, 2, 3, 4（左闭右开）
    print(i)

for i in range(2, 5):     # 2, 3, 4
    print(i)

for i in range(0, 10, 3): # 0, 3, 6, 9（步长 3）
    print(i)
```

`range(start, stop, step)` 和切片的规则**完全一致**（左闭右开），这是 Python 的又一个统一设计。

> 注意：`range(5)` 不是 `[0,1,2,3,4]` 这个 list，而是一个"惰性"的 range 对象，只在需要时一个个产出数字。
> 想看到内容，用 `list(range(5))`。

### `while` 循环

```python
count = 0
while count < 3:
    print(count)
    count += 1          # Python 没有 count++！
```

```text
0
1
2
```

**重点：Python 没有 `i++` / `i--`。** 自增必须写 `i += 1`。这是从 C/JS 过来的程序员最常"顺手写错"的地方：

```python
i = 0
i++            # ❌
```

真实报错：

```text
SyntaxError: invalid syntax
```

### `break` 和 `continue`

和 JS 语义一样：`break` 跳出整个循环，`continue` 跳过本次进入下一次。

```python
for n in range(5):
    if n == 2:
        continue      # 跳过 2
    if n == 4:
        break         # 到 4 就停
    print(n)
```

```text
0
1
3
```

注意：`break` 和 `continue` 只能用在循环里，用在循环外会报 `SyntaxError`：

```text
SyntaxError: 'break' outside loop
```

### `for ... else`：循环正常结束才走 else（冷门但面试爱考）

Python 的循环可以带一个 `else`，它的语义很特殊：**当循环"没有被 break 打断"而正常结束时，执行 `else`。**

```python
for n in range(3):
    print(n)
else:
    print("循环正常结束，没被 break")
```

```text
0
1
2
循环正常结束，没被 break
```

```python
for n in range(3):
    if n == 1:
        break
else:
    print("这句不会执行，因为 break 了")
```

**用途**：典型的场景是"找东西"——遍历找某个元素，找到就 `break`，没找到就走 `else`：

```python
names = ["alice", "bob"]
target = "carol"

for name in names:
    if name == target:
        print("找到了")
        break
else:
    print("没找到")        # carol 不在列表里，走这里
```

### `match / case`：结构匹配（Python 3.10+）

Python 3.10 终于加了 `match/case`，但它**不是** JS/C 里的 `switch`，而是更强大的**结构匹配（structural pattern matching）**。

最基本用法：

```python
def describe(x):
    match x:
        case 0:
            return "零"
        case int() as n if n > 0:     # 匹配类型 + 附加条件
            return f"正整数 {n}"
        case str():
            return f"字符串 {x}"
        case _:                        # _ 是"兜底"，类似 default
            return "其他类型"

print(describe(0))       # 零
print(describe(5))       # 正整数 5
print(describe("hi"))    # 字符串 hi
print(describe(1.5))     # 其他类型
```

它真正的威力在于**解构**——能直接匹配一个 tuple/list 的形状：

```python
def locate(point):
    match point:
        case (0, 0):
            return "原点"
        case (0, y):
            return f"在 y 轴上，y={y}"
        case (x, 0):
            return f"在 x 轴上，x={x}"
        case (x, y):
            return f"普通点 ({x}, {y})"

print(locate((0, 0)))    # 原点
print(locate((0, 5)))    # 在 y 轴上，y=5
print(locate((3, 4)))    # 普通点 (3, 4)
```

注意几个和 `switch` 的关键区别：

1. **`match` 默认不"穿透"**——匹配到一个 case 就结束，不需要 `break`（JS 的 `switch` 需要手动 break）。
2. **`_` 是兜底模式**，类似 `default`，匹配任何东西。
3. **能解构、能加 `if` 守卫**，这是传统 `switch` 做不到的。

`match/case` 需要 Python 3.10+，本教程基于 3.13，放心用。

> 一句话记住它：**Python 控制流的三大变化——`elif` 不是 `else if`、`for` 直接遍历元素不写 `i++`、没有 `i++` 只有 `i += 1`；`match/case` 是结构匹配不是 `switch`，不用 `break`、用 `_` 兜底。**

## 2.11 深浅拷贝：改副本为什么会影响原件

这是"可变对象是引用"（2.6 节）的直接推论，也是数据处理时的高频坑。

### 问题：`copy()` 只能"浅"复制一层

先看一个"浅拷贝"：

```python
import copy

orig = [[1, 2], [3, 4]]
shallow = copy.copy(orig)      # 浅拷贝：只复制"外层"，内层还是共享的

print(orig == shallow)             # True，值看起来一样
print(orig is shallow)             # False，但它们是两个不同的外层列表

print(orig[0] is shallow[0])       # True！内层列表还是同一个对象
```

关键在那句 `orig[0] is shallow[0]` 是 `True`——**浅拷贝只复制了"外层"列表，里面的子列表还是共享的同一个对象。**

后果：改内层，两边都变：

```python
orig[0].append(99)
print(shallow[0])     # [1, 2, 99]  ← 浅拷贝的内层被牵连了
print(orig[0])        # [1, 2, 99]
```

### `deepcopy`：完整复制每一层

```python
import copy

orig = [[1, 2], [3, 4]]
deep = copy.deepcopy(orig)       # 深拷贝：每一层都复制

print(orig[0] is deep[0])        # False，内层也不是同一个对象

orig[0].append(99)
print(deep[0])                   # [1, 2]  ← 深拷贝完全不受影响
```

### 一张图（表）记住区别

| 操作 | 外层对象 | 内层对象 | 改原对象的内层，副本会变吗 |
|---|---|---|---|
| `b = a`（赋值） | 共享（同一个） | 共享 | 会变 |
| `copy.copy(a)`（浅拷贝） | 新对象 | **共享** | **会变** |
| `copy.deepcopy(a)`（深拷贝） | 新对象 | 新对象 | 不会变 |

### 什么时候会踩这个坑

**只要你的数据结构是"嵌套的"（列表套列表、字典套列表），又想做一份独立的副本，就必须用 `deepcopy`。**

典型场景：你想复制一份配置、一份棋盘状态、一份游戏数据，改副本做实验，结果发现原件被跟着改了。
这就是浅拷贝在捣鬼。

还有一个相关的常见坑——`list` 的切片 `[:]` 和 `.copy()` 也都是**浅拷贝**：

```python
orig = [[1, 2], [3, 4]]
shallow2 = orig[:]          # 切片拷贝也是浅拷贝
shallow3 = orig.copy()      # .copy() 也是浅拷贝

print(orig[0] is shallow2[0])   # True
print(orig[0] is shallow3[0])   # True
```

**一句话结论：只有一层（简单元素）时，浅拷贝够用；一旦嵌套，要独立副本就用 `deepcopy`。**

> 一句话记住它：**`copy.copy` 只复制外层、内层共享，改内层两边都变；要真正独立的副本必须 `copy.deepcopy`——只要数据是嵌套的，就默认用深拷贝。**

## 2.12 本章常见坑速查

| 坑 | 现象 | 原因 | 正确做法 |
|---|---|---|---|
| 用 `is` 比较值 | `a is 1000` 结果时对时错 | `is` 比身份，且 CPython 有整数缓存/常量折叠 | 比较值用 `==`，只有 `is None` 用 `is` |
| 可变对象作默认参数 | 多次调用共享同一个 `[]` | 默认参数在定义时只创建一次 | 用 `None` + 函数内判空新建 |
| 浅拷贝当深拷贝 | 改副本内层，原件跟着变 | `copy.copy`/`[:]`/`.copy()` 只复制外层 | 嵌套结构用 `copy.deepcopy` |
| `nums = nums.sort()` | `nums` 变成 `None` | `sort`/`reverse` 原地修改，返回 `None` | 直接 `nums.sort()`，不接收返回值 |
| 取 dict 不存在的键 | `KeyError: 'age'` | 直接 `d[key]` 键不存在就报错 | 用 `d.get(key, 默认值)` |
| 循环里改列表 | 漏元素、结果诡异 | 遍历时删除会打乱迭代器 | 遍历副本 `for x in list[:]`，或新建列表收集 |
| 空 set 写成 `{}` | 得到的是空 dict | `{}` 被 dict 占用 | 空 set 用 `set()` |
| 单元素 tuple 写成 `(1)` | 得到的是整数 1 | tuple 的标志是逗号不是括号 | 写 `(1,)` |
| 用 `i++` | `SyntaxError` | Python 没有 `++` | 写 `i += 1` |
| `else if` | `SyntaxError` | Python 是 `elif` | 写 `elif` |
| set 用下标访问 | `TypeError: 'set' object is not subscriptable` | set 无序，无索引 | 用 `in` 判存在，或转 list |
| 用 `arr.length` 取长度 | `AttributeError` | Python 是 `len()` 函数 | 用 `len(arr)` |

---

## 2.13 本章小结

- 四个容器：`list` 可变有序、`tuple` 不可变有序、`dict` 键值映射、`set` 去重无序。
- **可变 vs 不可变**是核心：`list`/`dict`/`set` 可变，`int`/`str`/`tuple` 不可变。
- 赋值是"绑定标签"不是"复制值"：可变对象共享同一个身体，改一个全变。
- 可变对象不能作默认参数（`cart=[]` 的坑）；比较值用 `==`，只有判 `None` 用 `is`。
- 切片 `[start:stop:step]` 左闭右开，负索引从右数，`[::-1]` 反转、`[::2]` 隔一取一。
- 推导式一行顶 JS 三行：方括号=list、冒号=dict、花括号=set、圆括号=惰性生成器。
- 解包 `a, b = b, a` 交换、`*rest` 收集剩余、`enumerate` 拿下标、`zip` 配对。
- 控制流三大变化：`elif`、`for` 直接遍历元素、没有 `i++` 只有 `i += 1`。
- `match/case` 是结构匹配（3.10+），不用 `break`、用 `_` 兜底。
- 深浅拷贝：浅拷贝共享内层，嵌套结构要独立副本用 `copy.deepcopy`。

## 2.14 动手练习

1. 下面这段代码的输出是什么？为什么？

   ```python
   a = [1, 2, 3]
   b = a
   b.append(4)
   print(a)
   ```

   <details><summary>参考答案</summary>

   输出 `[1, 2, 3, 4]`。因为 `b = a` 是"引用赋值"，`a` 和 `b` 指向同一个列表对象。
   通过 `b.append(4)` 原地修改了这个列表，所以 `a` 也看到变化。这正是"可变对象赋值是共享引用"的体现。

   </details>

2. 下面代码会报什么错？为什么？怎么改？

   ```python
   point = (3, 4)
   point[0] = 99
   ```

   <details><summary>参考答案</summary>

   报 `TypeError: 'tuple' object does not support item assignment`。因为 `tuple` 是不可变对象，
   创建后不能改元素。如果确实需要能改的坐标，把 `tuple` 换成 `list`：`point = [3, 4]`；
   如果就是想要不可变的保护，那就不该改它。

   </details>

3. 写出下面每个表达式的值：

   ```python
   s = "abcdef"
   # 1) s[2:5]
   # 2) s[-3:]
   # 3) s[::-1]
   # 4) s[::2]
   ```

   <details><summary>参考答案</summary>

   - `s[2:5]` → `'cde'`（索引 2 到 5，左闭右开，取 c、d、e）
   - `s[-3:]` → `'def'`（从倒数第 3 个到末尾）
   - `s[::-1]` → `'fedcba'`（整个反转）
   - `s[::2]` → `'ace'`（步长 2，隔一个取一个）

   </details>

4. 用**列表推导式**写出"从 0 到 9 里，选出能被 3 整除的数，再平方"的结果。验证结果是不是 `[0, 9, 36, 81]`。

   <details><summary>参考答案</summary>

   ```python
   result = [n * n for n in range(10) if n % 3 == 0]
   print(result)   # [0, 9, 36, 81]
   ```

   `range(10)` 是 0~9，`if n % 3 == 0` 过滤出 0、3、6、9，`n * n` 再平方。

   </details>

5. 下面的函数有什么问题？写出修复后的版本，并解释原因：

   ```python
   def add_to(item, bag=[]):
       bag.append(item)
       return bag

   print(add_to(1))
   print(add_to(2))
   ```

   <details><summary>参考答案</summary>

   问题是可变默认参数：`bag=[]` 的 `[]` 在函数定义时只创建一次，两次调用共享同一个列表，
   所以第二次调用会得到 `[1, 2]` 而不是 `[2]`。修复：

   ```python
   def add_to(item, bag=None):
       if bag is None:
           bag = []
       bag.append(item)
       return bag

   print(add_to(1))   # [1]
   print(add_to(2))   # [2]
   ```

   默认参数用不可变的 `None`，在函数内部判断后再新建列表，保证每次调用都拿到新的空列表。

   </details>

6. 下面两段代码，`a` 分别是什么？为什么结果不同？

   ```python
   # 代码一
   import copy
   a = [[1, 2], [3, 4]]
   b = copy.copy(a)
   b[0].append(99)
   print(a)

   # 代码二
   import copy
   a = [[1, 2], [3, 4]]
   b = copy.deepcopy(a)
   b[0].append(99)
   print(a)
   ```

   <details><summary>参考答案</summary>

   - 代码一输出 `[[1, 2, 99], [3, 4]]`：`copy.copy` 是浅拷贝，只复制外层列表，
     内层的 `[1, 2]` 还是共享的，所以 `b[0].append(99)` 影响了 `a[0]`。
   - 代码二输出 `[[1, 2], [3, 4]]`：`copy.deepcopy` 是深拷贝，每层都复制，
     改 `b` 不影响 `a`。

   </details>

7. 用 `match/case` 写一个函数 `kind(x)`：`x` 是空列表返回 `"empty list"`，是只有一个元素的列表返回
   `"single"`，是其他列表返回 `"list"`，其余返回 `"other"`。（提示：用 `case []`、`case [_]` 匹配列表形状）

   <details><summary>参考答案</summary>

   ```python
   def kind(x):
       match x:
           case []:
               return "empty list"
           case [_]:
               return "single"
           case list():
               return "list"
           case _:
               return "other"

   print(kind([]))        # empty list
   print(kind([1]))       # single
   print(kind([1, 2, 3])) # list
   print(kind("hi"))      # other
   ```

   `case []` 匹配空列表，`case [_]` 匹配"恰好一个元素"的列表（`_` 是任意值），
   `case list()` 匹配其余列表，最后的 `_` 兜底。

   </details>

8. 解释为什么 `if x is None:` 是判断 `None` 的惯用写法，而不是 `if x == None:`？

   <details><summary>参考答案</summary>

   因为 `is` 比较的是对象身份（是不是同一个对象），而 `None` 是**单例**——整个进程里只有一个 `None` 对象。
   用 `is None` 判断既准确又高效。`==` 比较的是"值相等"，而一个自定义类的对象理论上可以"伪装"成和 `None` 值相等
   （通过重写 `__eq__`），所以 `== None` 可能被欺骗；`is None` 则绝对可靠。
   这是 `is` 唯一推荐的使用场景——其余地方比较值一律用 `==`。

   </details>
